# תאילנדיקה 🌺

אפליקציה ללימוד תאילנדית למתחילות דוברות עברית. ממשק עברי מלא בכיווניות RTL, שש יחידות לימוד,
כרטיסי לימוד, חידונים של 10 שאלות, השמעת הגייה תאילנדית, מעקב התקדמות ושמירה מקומית במכשיר.

בנוי ב-**React Native + Expo SDK 58 + TypeScript + Expo Router**. אין שרת, אין חשבון משתמש,
והכול עובד גם ללא חיבור לאינטרנט.

---

## הרצה מהירה

```bash
npm install
npx expo start
```

אז:

- **בטלפון** – להתקין את האפליקציה **Expo Go** (App Store / Google Play), ולסרוק את קוד ה-QR
  שמופיע בטרמינל. הטלפון והמחשב צריכים להיות על אותה רשת Wi-Fi.
  אם הרשת חוסמת, להריץ `npx expo start --tunnel`.
- **בסימולטור iOS** – ללחוץ `i` בטרמינל (דורש Xcode).
- **באמולטור אנדרואיד** – ללחוץ `a` בטרמינל (דורש Android Studio).
- **בדפדפן** – `npm run web` או ללחוץ `w`.

### פקודות

| פקודה | מה היא עושה |
|---|---|
| `npx expo start` | שרת הפיתוח לכל הפלטפורמות |
| `npm run web` | הרצה בדפדפן |
| `npm run ios` / `npm run android` | הרצה בסימולטור/אמולטור |
| `npm run typecheck` | בדיקת TypeScript |
| `npx expo export --platform ios --platform android --platform web` | בדיקת בנייה (bundling) לכל הפלטפורמות |

### התקנה כאפליקציה אמיתית בטלפון (ללא Expo Go)

```bash
npm install -g eas-cli
eas login
eas build:configure
eas build --platform android --profile preview
```

הפקודה מחזירה קישור להורדת קובץ `.apk` שאפשר להתקין ישירות באנדרואיד.
ל-iOS: `eas build --platform ios` (דורש חשבון Apple Developer).

> **שימו לב:** נתיב הפרויקט הנוכחי מכיל רווחים (`Application Support`). זה תקין ל-Expo Go
> ולדפדפן, אבל בנייה נייטיבית מקומית (`npx expo run:ios`) עלולה להיכשל בגלל הרווחים.
> לפני בנייה נייטיבית כדאי להעתיק את התיקייה לנתיב ללא רווחים, למשל `~/projects/thailandika`.

## התוכן הלימודי

שש יחידות, בכל אחת 10 פריטי לימוד ו-10 שאלות — בדיוק כפי שהוגדר באפיון:

| יחידה | תוכן |
|---|---|
| מילים חדשות | สวัสดี, ขอบคุณ, ใช่, ไม่, น้ำ, กาแฟ, บ้าน, เพื่อน, ดี, อร่อย |
| שיחות יומיומיות | ברכות מנומסות, היכרות, מה שלומך, סליחה, להתראות |
| אוכל ומסעדות | תפריט, אורז, עוף, דג, ירקות, לא חריף, חשבון, כמה זה עולה |
| טיולים והתמצאות | מלון, שדה תעופה, שירותים, שמאלה/ימינה/ישר, מונית, עזרה |
| מספרים | หนึ่ง עד สิบ (1–10) |
| משחקי ידע | חידון מעורב: זיהוי מילה, הקשבה, סיטואציה, זיהוי מספר |

כל פריט מוצג עם הכתב התאילנדי, תעתיק עברי מקורב ומשמעות בעברית.
**התעתיק העברי הוא קירוב בלבד** – תאילנדית היא שפה טונאלית, ויש להסתמך על ההשמעה.
לפני פרסום מסחרי יש לבדוק את כל התרגומים והתעתיקים מול דובר/ת תאילנדית.

## התנהגות החידון

מכונת מצבים: `question` → `correct-feedback` / `retry` → `completed`.

- **תשובה נכונה:** מסומנת ב-✓, מוצגות ההודעות "בחירה נכונה!" ו"עבודה מעולה", משוב חיובי קצר,
  ואחרי כ-1.1 שניות מעבר **אוטומטי** לשאלה הבאה. אין כפתור "הבא".
- **תשובה שגויה:** מסומנת ב-✕, מוצגת ההודעה "לא בדיוק — נסי שוב!" עם רמז. **נשארים באותה
  שאלה** ואפשר לנסות שוב, ללא הורדת נקודות.
- **ניקוד:** נקודה אחת לכל שאלה, רק על תשובה נכונה, ולכל היותר פעם אחת לשאלה.
  בזמן המשוב החיובי הבחירות נעולות כדי למנוע לחיצה כפולה.
- סדר אפשרויות התשובה מעורבב בכל הפעלה.
- יציאה באמצע שומרת את השאלה והניקוד; בחזרה לאפליקציה מופיע כרטיס "ממשיכים ללמוד".

## שמע

שכבת השמע מנסה, לפי הסדר:

1. **הקלטה מקורית** מתוך `src/audio/audioAssets.ts` – אם קיימת.
2. **מנוע ההקראה של המכשיר** (`expo-speech`) בשפה `th-TH`, עם בקרת מהירות מההגדרות.
3. אם אין אף אחד מהם – הכפתור מושבת ומוצגת ההודעה "השמע יתווסף בקרוב" / "לא הצלחנו להשמיע
   כרגע. אפשר להמשיך ולקרוא את הביטוי."

אין שמע פיקטיבי: כפתור שאין מאחוריו שמע אמיתי מוצג כמושבת עם הסבר.
השמעה אחת בכל רגע; מעבר בין מסכים עוצר שמע פעיל.

### הוספת הקלטות מקוריות

1. לשמור את הקובץ ב-`assets/audio/{categoryId}/{itemId}.mp3`
   (הרשימה המלאה: `assets/audio/MISSING_AUDIO.txt`, 50 קבצים).
2. לרשום אותו ב-`src/audio/audioAssets.ts`:
   ```ts
   export const RECORDED_AUDIO = {
     'words-1': require('../../assets/audio/words/words-1.mp3'),
   };
   ```
3. לעדכן את השדה `audio` של הפריט ב-`src/data/items.ts`.

## שמירה מקומית ופרטיות

`AsyncStorage` תחת המפתחות `thailandika:user`, `thailandika:progress`, `thailandika:settings`.
כל קריאה מהאחסון עוברת ולידציה ומחזירה ברירות מחדל אם הנתונים חסרים או פגומים.
שום מידע אינו נשלח לשרת, אין אנליטיקה, ואין בקשת הרשאת מיקרופון.
איפוס התקדמות דורש אישור מפורש.

## החלטות טכניות שהתקבלו בפיתוח

| נושא | ההחלטה | הסיבה |
|---|---|---|
| RTL | עיצוב RTL מפורש (`row-reverse`, `textAlign: 'right'`, `writingDirection`) במקום `I18nManager.forceRTL` | `forceRTL` דורש הפעלה מחדש של האפליקציה, מתנהג שונה ב-Web ועלול להתנגש עם היפוך ידני. הדרך הנוכחית זהה בכל הפלטפורמות. |
| טקסט תאילנדי | עטוף ברכיב `ThaiLabel` עם `direction: 'ltr'` | מונע היפוך סימנים בתוך ממשק RTL. |
| שמע | `expo-speech` כמנוע ברירת מחדל, עם תמיכה מוכנה בקובצי mp3 | אין עדיין הקלטות מקוריות, ו-TTS הוא הגייה אמיתית ולא "שמע מזויף". |
| ניגון קבצים | `expo-audio` (ולא `expo-av` שהוצא משימוש ב-SDK 58) | ה-API הנתמך בגרסת ה-Expo הנוכחית. |
| איורים | SVG מקורי (`react-native-svg`) – פיל, מקדש, עלי דקל, פרחים, גלים | אין שימוש בתמונות מוגנות; גם קל במשקל ומתאים לכל גודל מסך. |
| מסך רחב | התוכן ממורכז ברוחב מרבי של 600px | כדי שהממשק לא יימתח לרוחב מסך מחשב. |
| תפאורה | הרקעים הטרופיים של המוקאפ מומשו כאיורי SVG מקוריים (`TropicalScene`, `BeachScene`) ולא כתצלומים | כדי לא להשתמש בתמונות מוגנות, ובהתאם לסעיף 6 באפיון. גם נטען מיידית ומתאים לכל גודל מסך. |
| כפתור "לשאלה הבאה" | מופיע כמו במוקאפ, אך המעבר האוטומטי נשמר | האפיון דורש מעבר אוטומטי אחרי תשובה נכונה. הכפתור רק מקצר את ההמתנה של ~1.2 שניות. |
| הישגים וסטטיסטיקות | מחושבים מנתונים אמיתיים: רצף ימים, דקות לימוד בפועל ונושאים שהושלמו | אין מספרים מומצאים; מדליה נעולה מוצגת דהויה עם תנאי הפתיחה. |
| יחידת "משחקי ידע" | מתבססת על פריטים מהיחידות הקודמות (`GAME_ITEM_IDS`) | כפי שהוגדר באפיון: חזרה מעורבת על מה שכבר נלמד. |

## מגבלות ידועות

- **אין הקלטות של דובר/ת תאילנדית** – 50 קבצים ממתינים (`assets/audio/MISSING_AUDIO.txt`).
  ההגייה מגיעה ממנוע ההקראה של המכשיר. באנדרואיד ללא חבילת שפה תאילנדית מותקנת, כפתור
  ההשמעה יוצג כמושבת עם הסבר.
- התעתיקים בעברית הם קירוב ולא מייצגים טונים – דורש אימות עם דובר/ת תאילנדית לפני פרסום.
- יחידה אחת לכל קטגוריה בגרסה הראשונה; המבנה (`lessonIds`, `getQuestionsByCategory`) מוכן
  להוספת יחידות נוספות.
- אין תרגול דיבור עם זיהוי קולי – מוצגת רק ההנחיה "הקשיבי וחזרי בקול", כפי שהוגדר באפיון.
